# Decisiones de arquitectura (ADR)

Cada decisión importante se registra en un archivo numerado:

```text
0001-stack.md
0002-base-de-datos.md
0003-motor-de-audio.md
```

## Plantilla

```markdown
# ADR 0001 — Título

## Contexto
¿Qué problema o decisión tenemos?

## Decisión
¿Qué se decidió?

## Alternativas consideradas
¿Qué otras opciones había?

## Consecuencias
¿Qué ganamos y qué perdemos?

## Fecha y responsables
```

## Regla

Una decisión que afecte a más de una persona o que sea difícil de revertir debe quedar registrada aquí.
