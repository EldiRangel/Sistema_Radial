# Recursos

| Carpeta | Uso |
|---|---|
| `audio-demo/` | Audios de prueba con licencia libre para la demo y las pruebas. |
| `icons/` | Iconos de la aplicación y del instalador. |

## Reglas

- No subir música comercial sin licencia.
- Documentar la licencia de cada audio de demostración.
- Preferir archivos pequeños para las pruebas.
- Los audios grandes de producción no se versionan.
