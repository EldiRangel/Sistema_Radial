# Build

Recursos usados por `electron-builder` para generar el instalador.

| Carpeta | Uso |
|---|---|
| `icons/` | Iconos `.ico`, `.png` y recursos visuales del instalador. |

## Nota

La configuración del instalador vivirá en `electron-builder.yml` en la raíz del proyecto. Esta carpeta solo contiene recursos, no lógica.
